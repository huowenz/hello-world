# hello-world

## 本地麻将辅助算法

新增 `mahjong_helper.py`，可在离线环境下进行：

- 手牌解析（万/筒/索/字）
- 和牌判断（标准型 + 七对子）
- 向听数计算（标准型 + 七对子）
- 14 张手牌的弃牌建议（按向听和进张数排序）

## 运行方式

```bash
python3 mahjong_helper.py "123m456m789p11s22z"
```

或者：

```bash
python3 mahjong_helper.py "1m 2m 3m 4m 5m 6m 7p 8p 9p 1s 1s 2z 2z"
```

## 输出说明

- `向听 = -1`：已和牌
- `向听 = 0`：听牌
- `向听 > 0`：距离听牌还需改良的步数

当输入为 14 张时，会输出前 10 条弃牌建议。
